# Patterns - 패턴과 솔루션

## 역할

자주 사용하는 패턴과 해결책들을 모아둡니다.

## 들어갈 내용 예시

- 디자인 패턴
- 문제 해결 패턴
- 성능 최적화 방법
- 자주 쓰는 코드 구조

## LLM 사용 지침

- **문제 해결 시**: 새로 만들기 전에 이미 정의된 패턴이 있는지 먼저 확인
- **패턴 적용**: 해당 패턴의 장단점과 사용 조건을 이해하고 적용
- **일관성 유지**: 같은 종류의 문제는 같은 패턴으로 해결
- **파일 추가 시**: 이 목록에 새 파일 추가
