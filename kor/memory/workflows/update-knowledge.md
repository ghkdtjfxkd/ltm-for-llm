# 지식 업데이트

> memory 도메인 워크플로우: 기존 지식 문서를 수정

## 입력

- 대상 파일 경로
- 변경 내용

## 절차

### 1. 기존 문서 로드

`get-knowledge.md`를 통해 대상 문서 확인.

### 2. 변경 범위 판단

```
내용 추가/수정 → 해당 섹션만 수정
구조 변경 → 전체 재작성 고려
카테고리 변경 → 파일 이동 후 기존 파일 삭제
```

### 3. 문서 수정

- 내용 정확성 유지
- 짧고 집중적으로 (한 문서 = 한 주제)
- 관련 문서 링크 갱신

### 4. 출력

- 업데이트된 문서
- 변경 요약
