# 지식 조회

> memory 도메인 워크플로우: 필요한 지식을 찾아 로드

## 입력

- 카테고리 (선택)
- 키워드 또는 주제

## 절차

### 1. 카테고리로 범위 좁히기

```
키워드가 아키텍처 관련 → architecture/
키워드가 규칙/스타일 관련 → conventions/
키워드가 패턴/솔루션 관련 → patterns/
키워드가 오류/문제 관련 → troubleshooting/
키워드가 도메인 용어 관련 → domain-knowledge/
```

카테고리 불분명 → `memory/overview.md` 확인 → 하위 카테고리별 설명 읽고 결정.

### 2. 해당 카테고리 내 문서 탐색

카테고리 `overview.md` 확인 → 관련 문서 파일명 확인 → 해당 파일 읽기.

### 3. 출력

- 로드한 지식 내용
- 출처 파일 경로

## 주의사항

- **선택적 로드**: 필요한 문서만 읽음 (전체 카테고리 읽지 않음)
- **없는 경우**: 상위 워크플로우로 복귀하여 다음 단계 계속 진행. 해당 지식은 작업 완료 후 Binding(on-complete.md) 시점에 추가.
