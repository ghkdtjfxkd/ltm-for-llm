# 문서 작성 스타일

> conventions: LTM 문서를 작성할 때 따르는 규칙

## 내용

### 파편화 원칙

- **한 문서 = 한 주제**: 문서가 길어지면 분리
- **30줄 목표**: 초과 시 분리 검토
- **선택적 로드**: 읽는 쪽이 필요한 것만 선택할 수 있게

### 문서 길이

| 문서 유형 | 권장 길이 |
|----------|---------|
| entry.md | 20-30줄 |
| 워크플로우 | 30-50줄 |
| memory 노드 | 20-40줄 |
| overview | 20-30줄 |

### 헤더 형식

```markdown
# {제목}

> {카테고리}: {한 줄 요약}    ← 모든 AI용 문서에 포함
```

### 금지 사항

- 개인 작업 기록을 `/kor/`에 저장하지 않음
- 추상적 설명보다 구체적 예시 우선
- 중복 내용 (같은 정보를 여러 문서에 반복 X)

## 언제 사용

- 새 문서를 작성하기 전 스타일 확인
- 문서 리뷰 시 기준 참고
