# LTM 4계층 구조

> architecture: LTM 시스템의 핵심 디렉토리 구조와 각 계층의 역할

## 내용

LTM 시스템은 4개의 계층으로 구성됩니다:

```
{도메인}/
├── entry.md          # 외부 진입점 (인터페이스)
├── routing/          # 내부 라우팅 맵
├── workflows/        # 작업 처리 로직
└── {실제 데이터}/    # 지식/템플릿/태스크 등
```

**각 계층 역할:**

| 계층 | 역할 | 비유 |
|------|------|------|
| `entry.md` | 외부에서 들어오는 단일 창구 | API 엔드포인트 |
| `routing/` | 상황별 어디로 갈지 결정 | 라우터 |
| `workflows/` | 실제 작업 수행 방법 | 컨트롤러 |
| 데이터 폴더 | 실제 저장 내용 | DB |

## 언제 사용

- 새 도메인을 추가할 때 구조 참고
- 도메인 간 호출 방법을 설계할 때
- 어느 계층에 무엇을 작성할지 판단할 때
