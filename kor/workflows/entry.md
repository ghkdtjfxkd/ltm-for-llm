# Workflows Entry

> 외부에서 workflows 도메인으로 진입하는 문서

## 역할

사용자 요청을 적절한 최상위 워크플로우로 연결하는 진입점입니다.

워크플로우 선택이 필요하면 `../routing/main-routing-map.md`를 참조하세요.

## 지원 워크플로우

| 상황 | 워크플로우 |
|------|----------|
| 새 기능 개발 | `feature-development.md` |
| 버그 수정 | `bug-fixing.md` |
| 리팩토링 | `refactoring.md` |
| 문서 추가/수정 | `document-management.md` |
| 인지 OS 구조 변경 | `system-maintenance.md` |

## 사용 방법

1. 상황에 맞는 워크플로우를 위 테이블에서 선택
2. 워크플로우 문서를 읽고 단계별로 진행
3. 각 워크플로우가 하위 도메인(tasks, memory, templates)에 위임

## 관련 문서

- `../routing/main-routing-map.md` - 상황별 워크플로우 라우팅
- `overview.md` - 이 폴더 설명
