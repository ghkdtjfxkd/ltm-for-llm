# Templates

새로운 문서를 작성할 때 사용할 양식 모음.

## 파일 목록

| 파일/폴더 | 내용 |
|----------|------|
| `entry.md` | 외부 진입점: 템플릿 작업별 워크플로우 안내 |
| `workflow-template.md` | 오케스트레이터 워크플로우 작성 양식 |
| `memory-node-template.md` | 파편화된 지식 노드 작성 양식 |
| `routing-template.md` | 도메인 라우팅 맵 작성 양식 |
| `sync-check.md` | 도메인 동기화 상태 점검 양식 |
| `templates-routing.md` | Templates 도메인 내부 라우팅 맵 |
| `workflows/get-template.md` | 템플릿 가져오기 |
| `workflows/create-template.md` | 새 템플릿 만들기 |
| `workflows/apply-template.md` | 템플릿으로 문서 생성 |

## 사용 방법

1. 필요한 작업 → `entry.md`에서 워크플로우 선택
2. 워크플로우 따라 진행
3. 템플릿의 `{}` 항목 채우기
